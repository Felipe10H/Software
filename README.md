
# Software FJ

## Descripción
Software es un sistema desarrollado en Python para gestionar clientes, servicios y reservas. El proyecto utiliza programación orientada a objetos y manejo de excepciones.

## Funcionalidades
- Registro de clientes.
- Registro de servicios, como salas, alquiler de equipos y asesorías especializadas.
- Creación, confirmación y cancelación de reservas.
- Cálculo de costos de las reservas.
- Validación de datos y manejo de errores.
- Registro de eventos y errores en archivos de log.
- Demostración automática de operaciones para comprobar el funcionamiento del sistema.

## Tecnologías utilizadas
- Python 3
- Programación orientada a objetos
- Manejo de excepciones
- Registro de eventos mediante logs

## Archivos principales
- `main.py`: menú principal y ejecución de pruebas.
- `cliente.py`: gestión de clientes.
- `servicio.py`: definición de los servicios.
- `sistema.py`: administración del sistema.
- `excepciones.py`: manejo de excepciones personalizadas.
- `registro.py`: configuración de los registros de eventos y errores.

## Cómo ejecutar el programa
1. Instalar Python 3.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Ejecutar el archivo `main.py`.
4. Elegir la opción 1 para la demostración automática o la opción 2 para utilizar el menú interactivo.
